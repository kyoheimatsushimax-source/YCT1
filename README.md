# YCT1きゅう チャレンジ

YCT1級（中国語検定・ジュニア向け）合格のための子ども向け練習PWAです。

## 機能
- ことばカード：公式大綱の80語（音声・ピンイン・意味）
- れんしゅう：本番の7パート（聴力4＋読解3）と同じ形式、5問ずつ
- もぎテスト：35問・200点満点（120点で合格ライン）
- おとなのページ：試験概要、80語の意味一覧、試験日・読み上げ速度の設定、記録

## ファイル構成（すべて同じ階層・サブフォルダなし）
- index.html / manifest.json / sw.js
- icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png
- README.md

アイコンはサブフォルダに入れていません。GitHubのアップロード画面にファイルを全部まとめてドラッグすれば、そのまま反映されます。

## GitHub Pagesでの公開
1. 新しいリポジトリを作成（家族だけで使う場合もPagesのURLは公開になります。URLを知っている人だけが開ける想定）
2. このフォルダの中のファイル8個をすべてアップロード
3. Settings → Pages → Branch を main / (root) にして Save
4. 表示されたURLをiPhoneのSafariで開き、共有 →「ホーム画面に追加」

## 更新するとき
sw.js の1行目 `yct1-challenge-v1` の数字を上げてください（古いキャッシュが入れ替わります）。

## 音声について
端末内蔵の中国語読み上げ（Web Speech API）を使います。音が出ないときは消音スイッチと、
iPhoneの 設定 → アクセシビリティ → 読み上げコンテンツ → 声 に中国語があるかを確認してください。

## 注意
問題は公式大綱の語彙・文法に沿ったオリジナルで、公式過去問ではありません。得点は均等配点による目安です。
